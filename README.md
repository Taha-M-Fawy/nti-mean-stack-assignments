# NTI MEAN Stack Intensive Program — Labs & Assignments

This repository contains daily hands-on assignments, practical lab tasks, and mini-exercises developed throughout the **MEAN Stack Web Development Track** at the **National Telecommunication Institute (NTI)**.

---

## 📅 Track Modules & Timeline

| Module | Duration | Core Topics & Focus Areas |
| :--- | :--- | :--- |
| **01. JavaScript** | 2 Days | DOM Manipulation, Asynchronous Programming (XHR/Fetch), ES6+ |
| **02. MongoDB** | 3 Days | NoSQL Fundamentals, Schema Design, Aggregations, CRUD |
| **03. Node.js & Express** | 1 Week | RESTful APIs, Routing, Middlewares, Authentication, Error Handling |
| **04. Angular** | 1 Week | Architecture, Components, Services, RxJS, Routing, Reactive Forms |
